## AI Configuration

The application supports multiple AI providers:
- OpenRouter (recommended for production)
- OpenAI
- Anthropic Claude
- Google Gemini

To configure AI API keys, update the secrets:
```bash
kubectl create secret generic {{ include "todo-chatbot.fullname" . }}-ai-secrets \
  --from-literal=OPENROUTER_API_KEY=your-openrouter-key \
  --from-literal=OPENAI_API_KEY=your-openai-key \
  --from-literal=ANTHROPIC_API_KEY=your-anthropic-key \
  --from-literal=GOOGLE_API_KEY=your-google-key
```

Or use a more secure approach with external secret management like HashiCorp Vault or AWS Secrets Manager.
