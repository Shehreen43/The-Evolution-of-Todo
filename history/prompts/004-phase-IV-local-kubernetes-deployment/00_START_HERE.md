# Phase IV: Local Kubernetes Deployment - Getting Started

Welcome to the Claude Code prompts for Phase IV: Local Kubernetes Deployment. This collection of prompts will guide you through the specification, clarification, planning, and implementation of the Kubernetes deployment for the Todo Chatbot application.

## Directory Structure

### specification-phase/
Contains prompts for generating the initial specification for Phase IV

### clarification-phase/
Contains prompts for clarifying requirements and addressing ambiguities in the Phase IV specification

### planning-phase/
Contains prompts for creating the architectural plan and identifying architecturally significant decisions

### reference/
Contains reference documents and complete guides for Phase IV

## How to Use These Prompts

1. Start with the specification-phase prompts to define requirements
2. Move to clarification-phase if you encounter ambiguous requirements
3. Use planning-phase prompts to design the architecture
4. Reference the complete guides for comprehensive understanding

Each prompt is designed to work with Claude Code's agent capabilities and follows the Spec-Driven Development methodology.
